# 智慧树课程助手

适用于智慧树新版课程学习页面的 Chrome Manifest V3 扩展，当前版本 **1.6.1**。

支持视频课节连播、自动展开章节和滚动目录、随堂练习与章节测试、本地题库及可选的 OpenAI 兼容 API 答题。项目处于验证阶段，网站更新后可能需要重新适配。

## 安装

需要 Chrome 118 或更高版本。

**从源码安装：**下载或克隆仓库，在 `chrome://extensions/` 打开开发者模式，选择“加载已解压的扩展程序”，加载仓库中的 **`extension/`** 文件夹。

**从安装包安装：**解压 `zhihuishu-course-helper-v1.6.1.zip`，加载其中包含 `manifest.json` 的 `zhihuishu-course-helper/` 文件夹。

安装后刷新课程页。升级已有版本时替换原扩展文件并重新加载，再刷新课程页。不要同时启用多个版本。

## 功能与使用

1. 打开 `https://wisdom-mooc.zhihuishu.com/study/` 下的课程学习页面，右下角出现助手面板。
2. 按需开启本地题库或 API 答题。
3. 需要连播时，勾选“浏览器输入连播”；需要衔接章节测试时，同时勾选“连播时进入章节测试，完成后返回继续”。两个功能默认关闭。
4. 点击“启动助手”。“停止助手”会停止后续操作，已经发出的输入无法撤回。

视频播放结束后，助手按左侧目录顺序继续课程。目标所在章节折叠时会展开章节，目标不在可见区域时会滚动目录。出现练习或其他弹窗时暂停切课。未启用章节测试衔接时，连播会跳过测试条目。

切课通过 Chrome 浏览器输入接口执行。目录被遮挡、课节加载失败或页面异常时会停止，可在设置页查看切课日志。

随堂练习出现后优先使用已启用的本地题库；未匹配时可请求已配置的 API。整组题目匹配后选择并提交一次。未知题、已有手工选择、无效响应或未知弹窗等待人工处理。章节测试的“跳过”仅表示不点击该目录条目，不修改其完成记录。

## 章节测试（新标签页）

适配 `onlineexamh5new.zhihuishu.com/stuExamWeb.html#/webExamList/dohomework/` 下的章节、单元测试。

开启章节测试衔接后，本章视频播放结束会进入测试；确认提交成功后，助手关闭此次打开的测试页，返回原课程页继续连播。验证码、未知题目或异常提示需要人工处理，未确认完成时会保留测试页。手动打开的测试页不会自动关闭。

1. 在课程页启用需要使用的本地题库和/或 API；API 配置与视频内随堂练习共用。
2. 打开测试页，从第 1 题点击“启动 / 继续章节助手”。也可先在课程面板勾选“打开的章节测试页自动作答并提交”，之后打开测试页即可自动启动；该开关默认关闭。
3. 助手读取题干与选项，按已启用的答题来源逐题作答。
4. 勾选“全部作答后自动提交作业”时，完成后会提交并确认交卷；取消勾选则暂存作业，由你手动提交。

支持文字单选、多选和判断题；按选项内容匹配，不依赖随机排列的 A/B。题干通过 Chrome 扩展 DOM 接口读取，支持封闭 Shadow DOM。图片、填空、简答、无法解析的文字、未收录且 API 未启用的题目、已有不同答案、保存或翻页失败均停止，保留当前状态。只有交卷阶段的明确提交确认提示会自动确认；含未答提示、未知对话框及真实可见的验证码交给人工处理。

逐题 API 请求共用 5 秒调用间隔和会话次数上限。间隔未满时等待，不向服务商重复请求；网络、认证、额度或答案校验失败后需手动继续。页面刷新会清除本次答题进度跟踪，重新自动处理需回到第 1 题。

## API 设置

在面板中打开“API 设置”，填写服务地址、模型 ID 和 API Key：

| 项目 | 填写方式 |
| --- | --- |
| DeepSeek Base URL | `https://api.deepseek.com` |
| OpenAI Base URL | `https://api.openai.com/v1` |
| 其他兼容服务 | HTTPS Base URL 或完整 `/chat/completions` 地址 |
| 模型 | 服务商实际支持的模型 ID |

保存时自动补齐接口路径。点击“授权域名并保存”，再点击“测试 API 答题”。测试通过后回到课程页勾选“新题调用 API”，它可以独立于本地题库开关工作。

API Key、地址、模型和调用上限保存在本机扩展存储中，重启浏览器后仍保留，不进行浏览器账号同步。点击“清除 API 设置”可删除配置与密钥；卸载扩展会清除其本地数据。API 默认每次浏览器会话最多调用 30 次，包含测试和失败请求，可调整为 1–500 次。请求间隔至少 5 秒，25 秒超时，失败不自动重试。API 仅支持含文字选项的单选、多选题；模型答案不保证正确。

## 本地题库

在“本地题库与诊断”中填入 JSON 并保存。答案填写正确选项的完整文字，不填 A/B。保存会替换整份题库，追加题目时保留原有条目。

```json
[
  {
    "question": "完整题干",
    "answers": ["正确选项的完整文字"]
  }
]
```

弹题时可使用“提取当前题目模板”。本地题库默认为空，不内置课程答案。

## 权限与数据

| 权限 | 用途 |
| --- | --- |
| `storage` | 保存本地题库、偏好、持久 API 配置、会话调用计数与切课日志 |
| `debugger` | 在当前课程标签页读取状态，并发送目录点击和滚轮输入；Chrome 会显示调试提示 |
| `webNavigation` | 识别从原课程页打开的章节测试标签页 |
| 课程及测试站点访问权限 | 核对原课程页和测试页地址，管理对应测试标签页 |
| 可选 HTTPS 域名权限 | 仅在保存 API 设置时请求访问所填写的服务域名 |

`debugger` 是较强的浏览器控制权限，安装或升级时应核对 Chrome 的权限说明。实现只接受本扩展课程页发起的、经重新校验的下一视频请求，不接受任意网址或点击坐标，不自动连接其他标签页。

启用 API 时仅发送题干、题型和选项至所配置的服务，不发送账号、姓名或 Cookie。内容脚本仅注入课程域名及上文所列测试页面，章节助手只在对应作业路由中运行。不使用外部统计服务。最近 200 条切课日志仅保存在当前浏览器，日志不包含 API Key；提交问题前请自行检查日志内容。

## 故障与限制

- API 设置页 → “切课诊断日志” → “读取切课日志”，可查看最近的切课、展开、滚动和跳转错误。
- 若提示浏览器连接被占用，请关闭该标签页的开发者工具或结束其他正在控制它的浏览器任务。
- 建议保持课程标签页选中、Chrome 不最小化；长期后台运行尚未验证，浏览器节流可能导致延迟。
- 不修改学习时长、完成记录或平台校验脚本；登录、验证及未知弹窗需要人工处理。
- 已按真实页面 DOM 结构适配，并包含 123 项离线自动测试；测试模拟 Chrome 协议、标签页事件、HTTP 响应和章节测试状态，不代表真实环境整份交卷或长期连播已通过验证。
- 仅针对当前适配的课程页面，不保证全部课程、浏览器和网站后续版本都兼容。
